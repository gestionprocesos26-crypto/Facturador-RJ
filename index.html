⚙ Configuración

🤖 Anthropic API Key

¿Cómo obtener la API Key?
1. Ir a console.anthropic.com
2. Crear cuenta o iniciar sesión
3. Menú izquierdo → API Keys
4. Clic en Create Key
5. Copiar la clave (empieza con sk-ant-)
6. Pégala aquí y clic en Guardar

⚠ Los primeros $5 USD son gratis. Analizar ~200 fotos cuesta aprox $1.
Sin API key: la app usará OCR gratuito (Tesseract.js) para leer el texto de las imágenes y buscará los productos en el catálogo usando los sinónimos aprendidos. Funciona offline pero es menos preciso que la IA.

📖 Sinónimos aprendidos

Vincula el archivo sinonimos_rjch.json del repositorio — cada vez que se aprenda un sinónimo nuevo se guardará automáticamente en ese archivo, sin hacer nada.
⚠ La API key se guarda solo en tu navegador (localStorage). Nunca se envía a ningún servidor externo excepto a la API de Anthropic.
⚠ Abre la app desde el servidor local, no como archivo
Estás abriendo index.html directamente desde el disco — esto bloquea las llamadas a la API (error CORS).
Solución: abre una terminal en la carpeta del proyecto y ejecuta:
python3 server.py Luego ve a http://localhost:3000 en el navegador.
En Windows puedes hacer doble clic en iniciar.bat. En Linux/Mac ejecuta ./iniciar.sh.
